# ☕ 카페 온기 랜딩페이지

바쁜 하루 속 작은 쉼표를 콘셉트로 한 카페 "온기"의 소개용 원페이지 랜딩페이지입니다.

## 미리보기 섹션
- **Hero** — 카페 슬로건과 메뉴 바로가기 버튼
- **About** — 카페 소개 및 특징
- **Menu** — 추천 메뉴 4종과 가격
- **Location** — 위치, 영업시간, 연락처
- **Contact** — 문의 메일 안내

## 폴더 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 마크업 |
| `style.css` | 스타일 (반응형 포함) |

## 실행 방법
저장소를 내려받은 뒤 `index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

```bash
git clone https://github.com/eunpyo903-hash/cafe-landing.git
cd cafe-landing
start index.html   # Windows 기준
```

## 커스터마이징
- 카페 이름, 메뉴, 가격 등 텍스트는 `index.html`에서 수정할 수 있습니다.
- 색상 테마는 `style.css` 상단의 `:root` 변수 값을 바꾸면 전체 톤이 함께 바뀝니다.
